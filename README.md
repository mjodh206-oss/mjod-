# لصق فوري · سجل النسخ

**انسخ النص، فيُحفظ داخل التطبيق ويبقى حتى تحذفه بنفسك.** لا كتابة في حقول التطبيقات الأخرى، ولا إذن إمكانية وصول، ولا اختيار لتطبيقات المصدر أو الوجهة. تنفيذ وتطوير: أمجد حبيب.

## الاستخدام

افتح السجل واضغط **بدء الحفظ** مرة واحدة. يقبل النصوص والأرقام والروابط كما هي، دون تنظيف أو اختصار. الأحدث في الأعلى. اضغط النص لقراءته كاملاً، أو أيقونة النسخ لاستعادته للحافظة، أو سلة المهملات لحذفه. لمسح الكل استخدم «خيارات السجل ← مسح السجل كله». الإيقاف لا يمسح شيئاً.

| الجهاز | متى يُحفظ النص؟ |
|---|---|
| أندرويد ٨ و٩ | عند النسخ والخدمة الظاهرة تعمل، دون تبديل لوحة الكتابة. بعد إعادة تشغيل الجهاز افتح السجل لاستئناف الخدمة. |
| أندرويد ١٠ فأحدث + لوحة الحفظ محددة كلوحة حالية | عند تغيّر الحافظة، حتى داخل التطبيقات الأخرى. فعّل اللوحة واخترها من زر السجل مرة واحدة. هي لوحة كتابة محلية بسيطة تدعم العربية والإنجليزية والأرقام. يمكنك تبديلها من زر اللوحة. |
| أندرويد ١٠ فأحدث + لوحة كتابة أخرى | عند عودة التركيز إلى نافذة السجل يُحفظ آخر نص متاح تلقائياً، دون الضغط على لصق. أندرويد لا يسمح بجلب نسخ سابقة استُبدلت في الخلفية. المشاركة النصية إلى السجل متاحة أيضاً. |

الحفظ يتطلب موافقتك وجهازاً مفتوحاً والتطبيق غير موقوف قسراً. بلا أذونات خفية أو تجاوز لقيود النظام. لا نطلب إذن إشعارات أو استثناء بطارية على أندرويد الحديث. لا يوجد فحص دوري للحافظة؛ نعتمد على أحداث النسخ والتركيز.

## الاحتفاظ والخصوصية

- Room وSQLCipher (AES-256)، سرّ عشوائي مغلّف بواسطة Android Keystore، دون خادم أو إذن إنترنت. لقطات الواجهة محظورة، وقفل السجل باعتماد الجهاز اختياري من القائمة.
- لا مدد صلاحية ولا مهام تنظيف ولا حدّ لعدد النصوص سوى مساحة الجهاز. استعلامات العرض على دفعات ولا تقصّر السجل الفعلي. إعادة التشغيل وتغيير اللوحة والإيقاف لا تحذف النصوص. **إلغاء التثبيت أو مسح بيانات التطبيق من إعدادات أندرويد يزيلها**.
- لا نقرأ حقول الشاشة أو النص المحيط بالمؤشر أو نسجل المفاتيح. ننقل نص الحافظة الفعلي فقط (دون فتح مرفقات أو روابط). نتجاهل العلامة الحساسة، ونتجنّب الحفظ في سياقات كلمة المرور والتطبيقات الحساسة المعروفة عندما تتاح معلومات المحرر للوحة. لا يمكن معرفة المصدر الحقيقي لكل نسخة أو اكتشاف كل سرّ غير معلّم. لا نص في الإشعار.
- يحتفظ السجل بمؤشر آخر حدث داخل القاعدة المشفّرة، في نفس معاملة إضافة النص. إعادة الإشعار أو فتح السجل لا يكرّر العنصر ولا يعيد ما حُذف؛ **نسخ النص نفسه مرة أخرى** يُعدّ نسخة جديدة. النسخ من زر السجل لا يصنع حلقة. لا نغيّر حافظة النظام عند حذف نص محفوظ.
- النسخ الاحتياطي اليدوي محلي ومشفّر بعبارة مرور (AES-GCM وPBKDF2). يدعم ملفات الإصدار السابق دون إسقاط النصوص القديمة بسبب عمرها. حد ملف النقل ١٠٠٠ عنصر و٤ MiB، **ليس حداً للسجل**. لا نقتطع النصوص؛ تُستبعد حمولة حافظة واحدة تتجاوز ١٩٢ ألف وحدة UTF-16 تقريباً.
- قاعدة v2 تضيف مؤشر النسخ فقط؛ لا تحذف صفوف v1 عند ترقية بنفس الحزمة والتوقيع. حزمة التسليم التجريبية الجديدة منفصلة عن v1 ذات التوقيع المؤقت: **لا تلغِ تثبيت النسخة القديمة لنقل البيانات**. استخدم التصدير والاستيراد إذا رغبت.

## البناء والاختبار

Kotlin، Jetpack Compose وMVVM. يتطلب البناء JDK 17 وAndroid SDK 35. `./gradlew :app:testDebugUnitTest :app:assembleDebug`؛ الناتج `app/build/outputs/apk/debug/app-debug.apk`. لبناء إصدار دائم عيّن `LASQ_KEYSTORE` (مسار مطلق) و`LASQ_ALIAS` و`LASQ_STORE_PASSWORD` و`LASQ_KEY_PASSWORD` ثم نفّذ `:app:assembleRelease`. لا تُضمّن أي مفتاح توقيع في المستودع. يشغّل إصدار release التحقق من الشهادة وR8 ويبلّغ عن مؤشرات روت محلية دون استدعاء su.

مسار التسليم يبني APK تجريبياً شاملاً موقّعاً ويفحصه بـ apksigner، ويختبر على محاكيات API 26 و29 و35. يتضمن سيناريو نسخ فعلياً من تطبيق `fixtures` مستقل إلى **سجلنا فقط**، والحفظ عند الفتح، وإعادة التشغيل اليدوي، والحذف وعدم إعادة النص المحذوف. تطبيقات الاختبار ليست في APK المستخدم. لا تُغني المحاكيات عن تجربة الأجهزة الفعلية.
