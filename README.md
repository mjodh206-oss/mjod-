# مجودة (Majwuda)

مساعد ذكاء اصطناعي **عربي** يعمل بالصوت والنص، مبني حول Claude.
واجهته كاملة بالعربية (RTL) ويهدف إلى أن يكون «مساعد الجهاز» الحقيقي: يسمع، ويفهم، وينفّذ — بإذنتك.

تنفيذ وتطوير **أمجد حبيب**

## التحميل

أحدث إصدار ثابت: [مجودة v1.0.0](https://github.com/mjodh206-oss/mjod-/releases/tag/majwuda-v1.0.0)

- الحزمة: [`majwuda-v1.0.0.apk`](https://github.com/mjodh206-oss/mjod-/releases/download/majwuda-v1.0.0/majwuda-v1.0.0.apk) (Android 8.0+)
- البصمة: [`majwuda-v1.0.0.apk.sha256`](https://github.com/mjodh206-oss/mjod-/releases/download/majwuda-v1.0.0/majwuda-v1.0.0.apk.sha256)
  للتحقق بعد التحميل: `sha256sum -c majwuda-v1.0.0.apk.sha256`
- موقّعة بشهادة «Community Keystore» الموثّقة في [`signing/`](signing/README.md) و`version.properties` (versionCode = 10000 + رقم بناء CI).

### التثبيت

1. انقل الـAPK إلى الهاتف وفعّل «التثبيت من مصادر خارجية» له.
2. ثبّت مجودة وافتحها، ثم من **الإعدادات → الاتصال بكلود** أدخل مفتاح Claude API (يُخزّن محلياً في App-encrypted storage).
3. اختر الشخصية، الصوت، والوضع (فاتح/داكن/حسب النظام) من الإعدادات نفسها.

## ما الذي تستطيع مجودة فعله؟

- **محادثة متدفقة بالعربية** مع كشف العربية تشكيلًا وأسلوبًا ( IBM Plex Sans Arabic).
- **صوت كامل**: استماع (RECORD_AUDIO) وتحدّث عربي عبر TTS مع اختيار الصوت وضبط السرعة.
- **إجراءات بأدوات** مع تأكيد صريح قبل أي شيء حساس: اتصال، رسائل SMS، جهات الاتصال، سجل المكالمات، التقويم، التذكيرات، الملاحظات، الذاكرة طويلة المدى، الطقس، العملات، الحساب، البحث، الجهاز.
- **تكاملات النظام**: وضع المساعد الرقمي (ASSIST / VOICE_COMMAND)، ودجت الشاشة الرئيسية، بلاطة الإعدادات السريعة، اختصارات، التقاط صورة للمساعدة، وتذكير بالمهام.
- **خصوصية صريحة**: كل صلاحية حساسة تُطلب منك في وقتها، ولا تُطلب صلاحيات إضافية غير مصنّفة.

## البناء من المصدر

المتطلبات: JDK 17 + Android SDK (platform 35) + Gradle wrapper (يُنزَّل تلقائياً).

```bash
./gradlew :app:assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

توقيع الـrelease: القيم الافتراضية في `signing/keystore.properties` (شهادة مجتمعية موثقة) — يمكن استبدالها عبر متغيرات البيئة `MAJWUDA_KEYSTORE_FILE/PASSWORD/ALIAS/KEY_PASSWORD`. CI يبني ويوقّع تلقائياً عند الدفع إلى `arena/**` وينشر tag `majwuda-v*` كإصدار GitHub مرفق به الـAPK والبصمة.

## البنية

```
app/src/main/kotlin/app/majwuda/
├── assistant/    # المحرك، الأحداث، بناء البرومبت، ConfirmationHub
├── claude/       # عميل Claude (streaming) + تعريف الأدوات والمخططات
├── data/         # الإعدادات، والكتالوج، وكلاء الطقس/العملات، وRoom (رسائل/محادثات/ذاكرة/ملاحظات/تذكيرات)
├── services/     # ASSIST/الودجت/التايل/التذكيرات/الإشعارات/الوصولية/Wake-word
├── speech/       # تجريد STT/TTS
├── tools/        # أدوات المساعد (جهاز/تواصل/إنتاجية/معرفة) مع التأكيد للإجراءات الحساسة
└── ui/           # Compose RTL: شاشات الشات/الإعدادات/المحادثات/المحلية + المكونات (Orb…)
```
