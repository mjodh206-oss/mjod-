# QnS — تطبيق إدارة الإيداع والسحب

**تطوير وتنفيذ: أمجد حبيب**

تطبيق أندرويد عربي بالكامل (RTL) لتسجيل الإيداعات والمسحوبات بالليرة السورية، يعمل بدون إنترنت.

## ⬇️ التحميل

**[تحميل QnS.apk (آخر إصدار)](https://github.com/mjodh206-oss/mjod-/releases/latest/download/QnS.apk)**

## الميزات

- إيداع وسحب مع معاينة فورية للصافي المتبقي، ومنع السحب بأكثر من الرصيد.
- لوحة رئيسية: الرصيد الحالي، إجمالي الإيداع (أخضر)، إجمالي السحب (أحمر).
- سجل عمليات مع بحث وفلترة (اليوم / الأسبوع / الشهر / النوع).
- محافظ متعددة برصيد مستقل، تصنيفات، هدف ادخار مع شريط تقدّم.
- رسوم بيانية شهرية وتقارير PDF و Excel قابلة للمشاركة.
- تعديل وحذف العمليات مع تأكيد وسجل تعديلات.
- قفل برقم سري وبصمة الإصبع، نسخ احتياطي واستعادة، تذكير يومي.
- دولار كعملة ثانوية بسعر صرف يدوي، وضع داكن وفاتح، خط Cairo.
- شاشة افتتاح سينمائية ونغمات مولّدة للإيداع والسحب والافتتاح مع تحكم بالمستوى.
- أيقونة Adaptive مع نسخة أحادية اللون لأندرويد 13+.

## البنية

| المسار | الوصف |
| --- | --- |
| `www/` | واجهة التطبيق (HTML/CSS/JS بدون أي اتصال بالشبكة) |
| `android/` | مشروع أندرويد (Capacitor 8) |
| `tools/make_icons.py` | مولّد الأيقونات |
| `tests/smoke.mjs` | اختبارات المنطق الأساسية |
| `.github/workflows/build-apk.yml` | بناء الـ APK ونشره تلقائياً في Releases |

## التشغيل والبناء

```bash
npm ci
npm test            # الاختبارات
npm run serve       # معاينة في المتصفح على المنفذ 8080
npx cap sync android && cd android && ./gradlew assembleRelease
```
