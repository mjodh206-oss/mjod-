# تطبيق BNB — لتنظيم الراتب والميزانية الشخصية

**تنفيذ وتطوير: أمجد حبيب**

تطبيق عربي متكامل وسهل جداً يعمل **دون إنترنت بالكامل** (RTL) لأجهزة أندرويد 6.0 فما فوق (`minSdk = 23`)، مصمم ليمنحك خطة راتب واضحة وعملية خلال ثوانٍ بناءً على دخلك الحقيقي.

## أبرز المزايا
- **شاشة فتح وترحيب سلسة**: شعار BNB المتوهج، عملات تتساقط داخل المحفظة، وتوقيع «تنفيذ وتطوير أمجد حبيب».
- **إعداد فائق البساطة (خطوتين فقط أو خطة فورية بضغطة واحدة)**: اكتب راتبك واختر عملتك أو اضغط على الأرقام الجاهزة، وأجب على سؤالين بسيطين (إيجار؟ ديون؟).
- **خطتك الجاهزة بالمصاري (مو بالنسب)**:
  - حساب تلقائي للمصروف **اليومي والأسبوعي المسموح** حتى يكفي الراتب لآخر الشهر.
  - **4 خطط جاهزة بضغطة زر** (خطة متوازنة · توفير أكبر · للبيت أكثر · تسكير الديون).
  - **أظرف مالية واضحة (1 · 2 · 3 · 4)** تعرض لك بالمصاري الدقيقة كم تحط في كل بند فور استلام الراتب + تعديل سريع للراتب والمبالغ.
  - **المستشار الذكي بالذكاء الاصطناعي (مجاني)**: تحليل فوري لراتبك وإجابة على أسئلتك بالمبالغ الحقيقية عبر الذكاء الاصطناعي المجاني مع بديل ذكي يعمل حتى بدون إنترنت.
- **متابعة المصاريف والأهداف بـ 3 ثوانٍ**: زر `+ سجّل مصروف` عائم، أشرطة ألوان ذكية، تقارير أسبوعية وشهرية، أهداف ادخار مع احتفال عند الاكتمال 🎉، وخطة سداد الديون + تحدي الـ 30 يوم.
- **إضافات متكاملة**: تصدير تقرير شهري PDF بالعربية، نسخ احتياطي JSON، 4 ثيمات في الوضع النهاري والليلي، قفل PIN أو بصمة، إشعارات محلية بدون إنترنت، حاسبة ادخار، وويدجت للشاشة الرئيسية.
