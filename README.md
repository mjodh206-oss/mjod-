# تطبيق رَتِّبْ — لتنظيم الراتب والميزانية الشخصية

**فلوسك بتستاهل خطة**

**تنفيذ وتطوير: أمجد حبيب**

تطبيق أندرويد عربي بالكامل (RTL) مبني بـ **Flutter** ويعمل بدون إنترنت بالكامل (أندرويد 6.0 فما فوق).

## المميزات الرئيسية
- **خطة شهرية خلال ثوانٍ**: مبنية على قاعدة 50/30/20، صندوق الطوارئ، وسداد الديون أولاً.
- **شاشة فتح وترحيب تفاعلية**: عملات تتساقط داخل المحفظة، اسم «رَتِّبْ» بحركة كتابة، وصوت افتتاحي قصير.
- **معالج أسئلة بسيطة (سؤال في كل شاشة)**: بلوحة أرقام كبيرة ودعم لليرة السورية والدولار والعملات العربية والعالمية.
- **قلب التطبيق — شاشة الخطة**: رسم دائري تفاعلي (`fl_chart`)، مؤشر صحة راتبك من 100، منزلقات لحظية، وحساب الادخار السنوي.
- **النصائح الذكية**: نصيحة اليوم، تنبيهات مخصصة (مثل ارتفاع الإيجار فوق 40%)، تحدي الـ 30 يوم، وحاسبة سداد الديون (كرة الثلج / الانهيار الجليدي).
- **متابعة المصاريف والأهداف**: إضافة مصروف في 3 ثوانٍ، أشرطة تقدم ملونة (أخضر ← برتقالي ← أحمر)، تقارير أسبوعية وشهرية ومقارنة الخطة بالواقع، واحتفال بالقصاصات الملونة عند تحقيق الأهداف.
- **إضافات متكاملة**: وضع ليلي و4 أنماط ألوان، قفل بالبصمة والرمز، تصدير تقرير PDF عربي، نسخ احتياطي JSON، حاسبة ادخار سريعة، شارات وإنجازات، وويدجت للشاشة الرئيسية.
