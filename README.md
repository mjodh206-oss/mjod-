# نظام تشغيل قناة يوتيوب — Shorts تعليمية بالإنجليزي

> **تفويضك استلمته… بس خليني أكون صريحة من أول سطر** 👇
>
> 1. **ما بقدر أدخل لحسابك على يوتيوب، ولا أنشر فيديو، ولا أرد على تعليق باسمك من هنا.**
>    ما فيه رابط (connector) يوتيوب ولا Google بهالبيئة (تحققت)، وما بقدر — ولا المفروض — آخذ كلمة مرورك أو مفاتيحك أو أخزّنها بالمحادثة.
> 2. **الترند ما حدا بيضمنه.** يوتيوب بيقرر الانتشار من سلوك المشاهد، مش من العنوان. اللي بقدر أعمله هو أرفع احتماله: أول ثانية، الاحتفاظ لآخر ثانية، جودة العنوان/الصورة، وحركة التعليقات بأول ساعة.
> 3. **"التفويض" اللي بينفع فعلياً**: تفويض OAuth بتعمله أنت بمتصفحك وتحطه كـ GitHub Secret (أنا ما بشوفه)، مش كلمة سر بتعطيني ياها بالشات. بعدها المنظومة بتنشر وترد وتطلّع تقارير لحالها.

**اختياراتك:** محتوى تعليمي / معلومات · Shorts عمودية أقل من 60 ثانية · **بالإنجليزي** · المحتوى + أتمتة كاملة.

## 🆕 طلبت أداة على GitHub تتولى الموضوع كامل — لقيتها وربطتها

**المرشّح الأول:** [`darkzOGx/youtube-automation-agent`](https://github.com/darkzOGx/youtube-automation-agent)
(MIT · ~5,095 نجمة · آخر تحديث 2026-10-27 · Node ≥18.17). بيشتغل end-to-end: بحث مواضيع → سكربت/هوك/ميتاداتا → إنتاج MP4 حقيقي → مراجعة حقائق (Evidence desk) → جدولة ونشر **بعد موافقتك** → تحليلات → مزامنة التعليقات كل 4 ساعات و**مسوّدات ردود بموافقة صريحة وسقف يومي 50**. وعنده Shorts Repurposing Studio لتحويل الفيديو لـ 9:16.

فحصت كمان `n8n` (عقدة يوتيوب فيها رفع فيديو بس **ما فيها عمليات تعليقات**)، و`AI-Youtube-Shorts-Generator` (مصنع مقاطع 9:16، بلا نشر)، و`youtubeuploader` (رافع موثوق)، واستبعدت `ShortGPT` (آخر تحديث فبراير 2025). الجدول الكامل + المخاطر: **[docs/GITHUB_TOOLS.md](docs/GITHUB_TOOLS.md)**.

**اللي ربطته فعلياً:** `integrations/agent_bridge.py` بيولّد استراتيجية مقبولة من الـ API تبع الأداة (تحققت من قيمها بـ `index.js`: `explainer` / `short` / `engagement` / `status=draft`)، بيطلّع manifest للحلقات لـ Evidence desk، وبيفحص `/api/readiness`. **ما بفعّل الأداة ولا بوافق على فيديو** — هذول قرارك بالداشبورد.

### ⚠️ ليش ما بيصير "يبلش فوراً بالنشر" مع أي أداة؟
1. OAuth لازم يتعمل بمتصفحك أنت، على حساب القناة.
2. **مشاريع Google API الجديدة غير الموثّقة بترفع فيديوهات Private** (سياسة يوتيوب من 2020) — لازم طلب مراجعة compliance.
3. وضع OAuth "Testing" بينتهي بعد **7 أيام** → لازم نشر التطبيق أو إعادة تفويض أسبوعية.
4. الكوتا 10,000 وحدة/يوم ≈ **6 رفعات باليوم** (تقويمنا 6/أسبوع مريح).
5. لسه ما فيه ملفات MP4 — الحلقات سكربتات، والأداة الخارجية تحتاج مفتاح LLM + متصفح + OAuth عندك، فما بقدر أشغّلها هنا.
6. بوابة التحقق من الحقائق مقصودة: قناة تعليمية بتخسر ثقتها بمعلومة غلط واحدة.

**يعني:** أنا جهّزت كل شي لحد الخط، وأنت بتاخد **15 دقيقة تفعيل** → من بعدها الحلقة المجدولة بتنشر وترد وتطلّع تقرير بدون ما تلمسها. Checklist: **[docs/ACTIVATION.md](docs/ACTIVATION.md)**.

## التشغيل

```bash
# معاينة كاملة offline (لا مفاتيح ولا إنترنت مطلوب)
python automation/run_channel.py

# الحلقة كاملة فعلياً
python automation/run_channel.py --send --yes

# الأداة الخارجية (على جهازك أنت، بعد ما تشغّلها)
python integrations/agent_bridge.py strategy      # استراتيجية جاهزة، ما بتتبعت
python integrations/agent_bridge.py manifest     # حلقات لـ Evidence desk
python integrations/agent_bridge.py readiness    # فحص جاهزية الأداة

# اختبار المشروع
python -m unittest discover -s tests -v
```

الشرح الكامل (Google Cloud، الـ Secrets، الكوتا، بوابات الأمان): **[automation/README.md](automation/README.md)**

## البوابات اللي قصداً ما حذفتها

- **كل سكربت كتابة = dry run افتراضياً**، ما بينشر ولا بيرد إلا بـ `--send --yes`.
- **ما بينشر أي حلقة قبل `fact_check.verified = true`** — الحلقات الخمسة `verified: false` عن قصد.
- **ما بينشر أي فيديو ما حطّيته أنت بـ `publish_queue.json`**، وسقف رفعتين بالدورة الواحدة + فحص تكرار عبر الـ API.
- التعليقات الحسّاسة (طبي/قانوني/مالي/حقوق/بيانات شخصية) → **طابور بشري**.
- ولا كلمة سر ولا token بالريبو — `.gitignore` بيستبعد `.env` و `token.json` و `client_secret.json` والفيديوهات والتقارير.
