# سهرة الخميس 🕯️
تطبيق أندرويد عربي للأزواج، يعمل بمحتوى محلي ويجمع ألعاباً، مؤقتات، أجواء موسيقية، ألبوماً مشفراً وتذكيراً أسبوعياً.

## التشغيل والبناء
- `npm ci && npm run build:assets && npm test`
- `npm start` لمعاينة الواجهة. بناء أندرويد: Gradle 8.10.2، JDK 17 وAndroid SDK 35؛ يلزم تعيين `SAHRA_KEYSTORE` و`SAHRA_STORE_PASSWORD` لمفتاح PKCS12 باسم `sahra`.
- سير العمل في GitHub Actions ينشر APK؛ حالياً ينشئ مفتاح توقيع مؤقتاً لكل بناء بسبب عدم توفر صلاحية إعداد أسرار المستودع. لذلك لا يمكن تحديث تثبيت من بناء آخر مباشرة؛ يلزم إلغاء تثبيت النسخة السابقة (فتُحذف بياناتها) أو إعداد مفتاح توقيع دائم وآمن قبل الإصدار اللاحق.

## الخصوصية والحدود
- الألبوم يستخدم AES-GCM بمفتاح مشتق من الرمز عبر PBKDF2؛ البيانات محلية فقط وحذف التطبيق يحذفها، ولا يمكن استعادة الرمز. الرموز القصيرة ضعيفة أمام التخمين؛ استخدم رمزاً طويلاً.
- الرسائل الموقوتة محلية وليست إرسالاً بين الهواتف، والقفل الزمني واجهة تنظيمية وليس حماية تشفيرية.
- وضع لا موبايل يطلب إذن عدم الإزعاج، ولا يقفل الهاتف؛ النظام وإعدادات الاستثناءات وتوفير الطاقة قد تؤثر على الكتم ومدته. التنبيهات تحتاج إذن إشعارات وقد تتأخر بسبب النظام.
- ألعاب التطبيق اختيارية وبموافقة الطرفين، ويمكن تخطي أي تحدٍّ.
