# مصروفي

محفظة شخصية عربية بسيطة لتسجيل الإيداعات والمسحوبات بالليرة السورية. التطبيق يحسب الرصيد الحالي ومجموع ما أودعته وما سحبته. البيانات محفوظة محلياً على الجهاز ولا ترسل إلى خادم.

## تطبيق أندرويد (APK)

مشروع Android الأصلي موجود في `android/`. سير العمل في GitHub Actions يبني APK موقّعاً بمفتاح التصحيح لأغراض التثبيت المباشر، ثم ينشره كأصل إصدار GitHub Release. شغّل سير العمل **Build Android APK** من تبويب Actions، أو نزّل أحدث إصدار أندرويد من صفحة Releases في المستودع.

## تشغيل نسخة الويب

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

افتح `http://localhost:4173`. يمكن تثبيت نسخة الويب كتطبيق PWA وتعمل بلا اتصال بعد أول تحميل. ملفات الحركات محفوظة في التخزين المحلي للمتصفح؛ حذف بياناته يمسح الحركات المحفوظة.
