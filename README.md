# ريموتي

واجهة ويب عربية قابلة للتثبيت (PWA) لتنظيم الأجهزة والغرف وتجربة واجهة ريموت. تُحفظ البيانات محلياً وتتوفر نسخة احتياطية بصيغة JSON.

## التشغيل

شغّل خادماً محلياً من المجلد، مثلاً `python3 -m http.server 8000`، ثم افتح الصفحة في المتصفح. يعمل التثبيت والعمل دون اتصال عبر HTTPS أو localhost بعد تحميل التطبيق أول مرة.

## حدود النسخة

الأجهزة والأزرار والوضع الليلي تجريبية فقط؛ لا يوجد اكتشاف تلقائي أو اتصال حقيقي بالأجهزة. التحكم الفعلي يتطلب تكاملاً مع أجهزة أو بروتوكولات متوافقة (مثل مرسل IR أو واجهات شبكة معتمدة). المؤقت تذكير أثناء فتح الصفحة ولا يطفئ الأجهزة. لا تتوفر ودجت نظام أصلية. تتوفر نسخة Android منفصلة تشمل تجربة إشارات IR محدودة للتلفزيونات؛ راجع `android/README.md`.
