# نظام تشغيل قناة يوتيوب — Shorts تعليمية بالإنجليزي

> **تفويضك استلمته… بس خليني أكون صريحة معك من أول سطر** 👇
>
> 1. **ما بقدر أدخل لحسابك على يوتيوب، ولا أنشر فيديو، ولا أرد على تعليق باسمك من هنا.**
>    ما فيه رابط (connector) يوتيوب بهالبيئة، وما بقدر — ولا المفروض — آخذ كلمة مرورك أو مفاتيحك أو أخزّنها.
> 2. **الترند ما حدا بيضمنه.** يوتيوب بيقرر الانتشار من سلوك المشاهدين، مش من العنوان. اللي بقدر أعمله هو أرفع احتماله لأقصى درجة: أول ثانية، الاحتفاظ للمشاهد لآخر ثانية، جودة العنوان/الصورة، وحركة التعليقات بأول ساعة.
> 3. **اللي سلّمته فعلياً**: نظام تشغيل كامل للقناة في هالريبو — سكربتات جاهزة، هوكات، عناوين، ردود تعليقات، تقويم 30 يوم، **وسكربتات Python + GitHub Actions بتنشر وترد فعلياً بمفاتيحك أنت**. أنت بس بتضيف الـ OAuth secrets مرة واحدة وبترفع ملف الفيديو.

**الاختيارات اللي أخذتها منك:** محتوى تعليمي / معلومات · Shorts عمودية أقل من 60 ثانية · **بالإنجليزي** · المحتوى + نظام أتمتة كامل.

## كيف بتشغّله (3 خطوات)

```bash
# 1) مرة واحدة: مكتبات + تسجيل دخول يوتيوب من متصفحك
python3 -m pip install -r requirements.txt
python automation/auth_setup.py --client-secret /path/to/client_secret.json
cp .env.example .env      # حط مسار token.json

# 2) شوف المحتوى الجاهز
python tools/validate_content.py
python tools/render_scripts.py       # يطلع content/SCRIPTS.md

# 3) أول فيديو (معاينة، بعدين نشر)
python automation/publish_video.py --episode ep-001 --file ~/renders/ep-001.mp4
python automation/publish_video.py --episode ep-001 --send --yes
python automation/reply_to_comments.py --send --yes --max-replies 30
```

## البوابات اللي قصداً ما حذفتها

- **كل سكربت كتابة = dry run افتراضياً**. ما بينشر ولا بيرد إلا بـ `--send --yes`.
- **ما بينشر أي حلقة قبل `fact_check.verified = true`**. الحلقات الخمسة اللي سلّمتها `verified: false` عن قصد — لازم تتأكد من المصدر قبل أول نشر. قناة تعليمية بتخسر ثقتها بمعلومة غلط واحدة.
- **التعليقات الحسّاسة (طبي/قانوني/مالي/حقوق/بيانات شخصية) بتروح لطابور بشري**، ما بيرد عليها بوت.
- **ما بيتكرر الرد**، ولا بيرد على تعليقات القناة نفسها، ولا على سبام أو روابط.
- **ولا كلمة سر ولا token بالريبو** — `.gitignore` بيستبعد `.env` و `token.json` و `client_secret.json` وملفات الفيديو والتقارير.

## يعني شو صار بالتفويض؟

صار عندك **خط إنتاج + خط نشر + خط تفاعل** شغّالين: أنا جهّزت المحتوى والمنطق والكود، والمنظومة بتنفّذ بمفاتيحك أنت على حسابك أنت. أول قرار لازم تاخده: **وثّق مصادر الحلقات الخمسة** وبعدها انشر أول واحد بالتقويم (الثلاثاء 10 نوفمبر 2026، 17:30 UTC).

إذا بدك كمّل: قوللي أنهي سلسلة بدك أوسّعها، وبكتب لك الـ 5 حلقات الجاية بنفس البنية، وأضبط الهوكات على نتائج `reports/latest.md`.
