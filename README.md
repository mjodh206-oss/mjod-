## 🧠 المستشار المالي (تنبيهات وخطط ذكية)
محرك قواعد يفحص بياناتك الحقيقية وينبّهك عند:
- تجاوز الميزانية الشهرية، أو إيقاع صرف أسرع من أيام الشهر، أو الاقتراب من السقف (80٪+).
- مصروف شاذ (أكبر من 10 أضعاف متوسط يومك).
- فئة ملتهبة تلتهم >40٪ من مصروفك.
- تسريبات متكررة (اشتراكات والتزامات ثابتة).
- ديون متأخرة أو تستحق خلال 7 أيام، وديون تتجاوز 3 أضعاف دخلك.
- انقطاع عن التسجيل ≥4 أيام، ووسادة نقدية دون 3 أشهر.

ويولّد **خطة عمل شخصية** مرتبة (سقف، ادخار يوم الراتب، خفض أكبر فئة، خطة سداد كرة الثلج، صندوق طوارئ، اجتماع شهري).

## 🔐 الأمان والخصوصية
- **فتح بالبصمة فقط** (BiometricPrompt، أو قفل النظام على أندرويد 7/7.1) مع خيار «بصمة فقط بدون رمز»، أو رمز PIN احتياطي مجزّأ بـ SHA-256 + ملح عشوائي.
- قفل تلقائي عند خروج التطبيق من المقدمة.
- **صفر إنترنت**: لا إذن INTERNET في الـ Manifest أصلًا.
- نسخ احتياطي JSON/CSV محلي تُصدّره وتشاركه كيفما تشاء وتستعيده بضغطة.

## 🎨 التصميم
- هوية زمرّدية/ذهبية، وضع فاتح وداكن، خط IBM Plex Sans Arabic (OFL) مضمّن بالأوزان الأربعة.
- رسوم بيانية مرسومة يدويًا (Canvas): دونات، أعمدة يومية، حلقات تقدّم.
- أيقونات Material مرسومة متجهيًا (58 أيقونة) + شعار أصلي (عملة + ميم + شارة توثيق).
- تذكير يومي ذكي عبر AlarmManager + قنوات إشعارات، يُعاد جدولته بعد إعادة التشغيل.

## 🛠 البناء من المصدر (بدون إنترنت!)
سلسلة الأدوات كلها مرايا على GitHub (JDK 17 + build-tools 34 + platform 34):

```bash
./tools/build-apk.sh
# الناتج: dist/Mahloula-v1.0.0.apk موقّع بـ apksigner (v1+v2+v3)
```

المسارات داخل السكربت: `aapt2 compile → aapt2 link → javac (bootclasspath=android.jar+core-lambda-stubs) → d8 → zip (dex+assets) → zipalign → apksigner`.
