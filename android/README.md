# نسخة أندرويد

غلاف Android WebView محلي، مع جسر أصلي مقيد لإرسال أكواد IR للتلفزيون عبر ConsumerIrManager. لا يحتاج إلى الإنترنت. يستهدف Android 6.0 وما فوق، ويتطلب هاتفاً يحتوي على مرسل IR فعلي. ملفات Samsung وLG هي ملفات شائعة وليست ضماناً للتوافق مع كل موديل. البحث هو إرسال إشارات تشغيل يدوياً والتأكيد عند استجابة التلفزيون، وليس كشفاً تلقائياً. لا تتوفر حالياً أكواد حقيقية للمكيفات أو المراوح أو الرسيفرات والإضاءة. المؤقت والوضع الليلي محاكاة، والنسخ الاحتياطي وتثبيت PWA غير متوفرين داخل نسخة أندرويد.

يمكن بناء APK بأدوات Android SDK: حزم موارد `android/app/src/main` باستخدام aapt، وتجميع MainActivity.java ضد android.jar، وتحويل الناتج إلى dex، ثم حزم ملفات الويب في assets والتوقيع. نسخة التطوير الموزعة موقّعة بمفتاح تجريبي وليست جاهزة للنشر على المتجر.
