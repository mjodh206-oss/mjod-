## المميزات السينمائية
- **هوك في 0.02 ثانية**: النص ينزل بـ blur + الكلمة الذهبية تظهر بضربة (scale punch) + خط ذهبي يتمدّد تحتها.
- **كارةوكي**: كل كلمة تنوّر مع توقيت التعليق (نفس توقيتات الصوت بالظبط من `build/subs.ass`).
- **Aurora + Light sweep**: إضاءة ذهبية بتتحرك وراء الكادر — إحساس إعلان فاخر.
- **Progress bar** في الأعلى (يوتيوب بيدعمه نفسيًا كمؤشر إكمال).

## ازاي تعيد الرندر / تعدّل
```bash
# 1) تجهيز المتصفح (مرة واحدة)
npm i puppeteer-core @sparticuz/chromium
node -e "require('@sparticuz/chromium').executablePath()"   # يفكّ ضغط Chromium
#    لازم مكتبات NSS من al2023.tar.br اللي جوه الحزمة (موجودة في /tmp/al/lib في السESSION)

# 2) سكرينشوتس سريعة للمراجعة
node build/motion/render.mjs --stills=1.5,22,42

# 3) الرندر الكامل (≈15 دقيقة على 2 cores)
node build/motion/render.mjs --out=output/money_shorts_v2.mp4
```

- تعديل النصوص/التوقيتات: `build/motion/index.html` (قسم `MASTER TIMELINE`).
- تعديل الصور: `assets/scene*.jpg`.
- الصوت: `build/mix.wav` (تعليق + ساوند ديزاين مُصنّع).
