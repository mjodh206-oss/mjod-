# موشن غرافيك ماري سيليست V4 / تحديث V6

محرك Remotion/React يبني المشاهد برسوم SVG متحركة، لا بتحريك صور ببطء. تحديث V6 يفصل السرد إلى لوحات بصرية متغيرة: افتتاح البحر والسفينة، خريطة رحلة كاملة، سجل حمولة ١٬٧٠١ برميل، تكبير سجلّ الملاحة، قائمة أفراد الطاقم، لقطة قارب النجاة المفقود، لوحة أدلة التحقيق، ثم ثلاث فرضيات مرئية وخاتمة رمزية. لذلك لا تبقى السفينة في مركز الصورة طوال الحلقة. تتغير نقطة التركيز والحركة داخل المشاهد الطويلة أيضًا، مع ظهور الأدلة تباعًا وتناوب إبراز الفرضيات بدل ثبات البطاقات. للشورت تكوين عمودي مستقل وإيقاعه الخاص، والترجمة العربية مرتبطة بإطارات التايملاين.

## ملفات V6 الناتجة

- `deliverables/episode-01-main-motion-v6.mp4` — أفقي 1280×720، 24fps، 5433 إطارًا (3:46.375).
- `deliverables/episode-01-short-motion-v6.mp4` — عمودي 720×1280، 24fps، 1100 إطار (45.833 ثانية).
- `brand/episode-01-short-cover-v6.png` — غلاف عمودي 1080×1920، بخط عربي واضح ومقروء.
- كلا الملفين H.264/AAC. تُضاف مؤثرات Foley إجرائية مخصصة لكل فصل: رنين خفيف للخريطة، خشب وبراميل، تقليب الورق، حبال وأمواج، ونقرات انتقالات التحقيق. يُنشأ خفض تلقائي للمؤثرات اعتمادًا على مستوى التعليق حتى تبقى الكلمات واضحة.

## إعادة البناء

من جذر المستودع:

```bash
npm install --prefix scripts/remotion-v4
node scripts/remotion-v4/render.mjs
node scripts/remotion-v4/render.mjs --short
node scripts/remotion-v4/render.mjs --cover
python -m pip install -r scripts/requirements-motion.txt
node scripts/remotion-v4/finalize.mjs
```

اختبار صورة مفردة: `node scripts/remotion-v4/render.mjs --still`، وللشورت أضف `--short`. ينتج `--cover` غلاف الشورت كـPNG. يمكن اختيار إطار المعاينة عبر متغير `FRAME`.

يقرأ المشروع التايملاين والترجمات من `scripts/remotion-v3/timeline-v3.json`، ويأخذ التعليق من مكس V3. يولّد Foley أصليًا عند مدد المشاهد الدقيقة، ثم يقرأ `mix_audio.py` طاقة التعليق على نوافذ ١٠ مللي ثانية ويخفض المؤثرات تلقائيًا أثناء الكلام مع هجوم/تحرير ناعم، من دون sidechain filter خارجي. يُنتج `finalize.mjs` نسختي H.264/BT.709 مع AAC. أسماء المخرجات V6؛ لا يُستبدل بها إصدارا V4/V5 السابقان. الغلاف مرسوم بـSVG داخل Remotion لأن تكامل Gemini المباشر غير متاح في هذه الجلسة؛ لم أصفه على أنه مولّد بواسطة Gemini.
