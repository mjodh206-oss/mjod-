# تحسين حركة الحلقة — وراء الحكاية

## اختيار الأداة من GitHub
راجعت أدوات توليد الفيديو المفتوحة المصدر الأعلى شعبية على GitHub وقت التنفيذ:

- [Wan2.1](https://github.com/Wan-Video/Wan2.1) — قرابة 17.5 ألف نجمة في GitHub وقت الفحص، ويدعم توليد الفيديو من النص/الصورة وتحرير الفيديو. يذكر مستودعه أن نموذج T2V-1.3B يحتاج نحو 8.19 GB من ذاكرة GPU، وأن مقطعًا 480p مدته 5 ثوانٍ يستغرق نحو 4 دقائق على RTX 4090.
- [CogVideo](https://github.com/zai-org/CogVideo) — قرابة 13.2 ألف نجمة وقت الفحص، ويدعم توليد الفيديو من النص والصورة.

**سبب عدم تشغيل Wan2.1 هنا:** بيئة التنفيذ الحالية لا تحتوي على بطاقة NVIDIA أو أوزان نموذج الفيديو، وتنزيل الأوزان غير متاح في هذه البيئة. لذلك لم أدّعِ أن اللقطات مولّدة بنموذج فيديو. بدلًا من ذلك نفّذت مسارًا محليًا قابلًا لإعادة التشغيل باستخدام Python وPillow وNumPy وFFmpeg، من دون الاعتماد على خدمة خارجية.

## ما الذي يتحرك في النسخة الجديدة؟
شغّل `render_mary_celeste_motion.py` لإنتاج `Mary-Celeste-main.mp4` من الأصول المحلية:

- السفينة تتحرك أفقيًا، تتمايل مع الموج، وتبتعد تدريجيًا في الخاتمة.
- سطح البحر يتحرك بإزاحة موجية، مع رغوة ولمعان متحركين أمام بدن السفينة.
- خط الرحلة على الخريطة يُرسم تدريجيًا، ويتحرك عليه مؤشر سفينة.
- لقطة السطح فيها تمايل كاميرا ومطر/رذاذ متحرك.
- ملف التحقيق يظهر بحركة دخول وتقليب بسيطة، مع تغير إضاءة المصباح.
- التعليق والترجمة العربية محروقَان داخل الفيديو، مع وسم واضح بأن الصور تمثيلية.

هذه معالجة **موشن غرافيك ثنائية الأبعاد** وليست تصويرًا حيًا أو فيديو مولّدًا بالكامل بالذكاء الاصطناعي. الخطوة الأعلى جودة مستقبلًا هي توليد عدة لقطات قصيرة بالصورة إلى الفيديو عبر Wan2.1 على جهاز GPU مناسب، ثم مونتاجها حول التعليق الصوتي.

## التشغيل

```bash
python -m pip install -r scripts/requirements-motion.txt
python scripts/render_mary_celeste_motion.py --output Mary-Celeste-main.mp4
```

الأصول المطلوبة موجودة ضمن `brand/motion/` و`brand/episode-01-visuals/`، والتعليق والترجمة في `audio/episode-01/` و`deliverables/`.
